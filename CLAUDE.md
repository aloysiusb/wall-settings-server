# Read this first, every session

Sessions in this repo are usually **EverGreen ZeroWaste office work** (Virginia),
not this wall-settings server. Before answering anything about EverGreen:

1. **Current status of everything:** `public/office/status/` in the
   `aloysiusb/evergreen-driver-app` repo (newest dated page; served at
   https://evergreen-driver-app.onrender.com/office/status/latest behind the
   office login). Attach that repo with `add_repo` and read the newest page.
   Its `CLAUDE.md` has the standing rules.
2. **Drive, folder "CLAUDE HANDOFF":** the newest `HANDOFF …` doc, plus
   "CLAUDE HANDOFF — READ FIRST", "BILLING PROTOCOL v3/v3.1", and the
   new-customer welcome email template.

**Every bill, pay link or past-due email to a customer** uses Virginia's format:
short, easy to read, the amount in bold, one big green **"Pay $X now"** button
(bank link first, no fee), a pay-by date, the AutoPay ask, signed Virginia.
Template: `public/office/rules/pay-link-email-template.html` in
`aloysiusb/evergreen-driver-app`. Never send a plain-text bill or a bare link.

Before the session ends, copy the status page to today's date, update it, and
push. Nothing is kept only in a session's memory or scratchpad: scratchpads are
wiped.

Anything that has to happen in QuickBooks on the web (recurring payments,
cancelling autopay) is done by Claude in Chrome on Virginia's computer. Write
those steps into a dated `HANDOFF … Chrome tasks` doc in the Drive CLAUDE
HANDOFF folder.
